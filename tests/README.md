# Автотесты SKKG Pro

Робот открывает приложение в браузере, нажимает кнопки и сверяет результат с заранее известными числами.

- Запускаются сами при каждом изменении в GitHub (Actions → CI → задача `autotests`).
- Обязательно запускаются перед публикацией (Actions → Deploy): если хоть одна проверка не прошла, сайт не обновится.
- Итог по-русски виден на странице запуска в разделе **Summary**.

Вместо настоящей базы используется подменная (`fake-supabase.js`), вместо настоящего чертежа — вымышленный лист
`fixtures/test-sheet.html` (собирается командой `node make-fixture.js`). Реальные данные и ключи в тестах не участвуют.

Запуск на своём компьютере: `cd tests && npm install && npx playwright install chromium && node run.js`.

Новая функция приложения → новая проверка в `run.js` (блок `test('Название', async () => { ... })`).
